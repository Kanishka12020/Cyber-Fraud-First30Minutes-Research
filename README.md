## Evidence integrity and limitations

This repository supports **literature-search and reference documentation**. It does not contain original survey responses: **no primary survey was conducted**. The published surveys, government statistics and police-reported cases discussed in the paper are **secondary evidence**. This repository does not independently validate their findings.

The recorded search flow is **486 identified, 412 screened after deduplication and 32 included in the core review**. These counts are copied from the project documentation and have **not been independently rerun or audited**. The reference metadata, matrix entries and published numerical claims also require verification against original publications.

An earlier version of this project used a 164-case **synthetic simulation**. Its simulated dataset and figures are intentionally excluded because the current report is a secondary-evidence literature review, not an experiment with human participants.

## Reproducing the review

1. Examine the recorded search terms, dates and hit counts.
2. Compare the literature matrix against the 32 core references.
3. Consult original publications before relying on numerical claims.
